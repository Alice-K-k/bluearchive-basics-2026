# 《计算机基础》课程设计 —— 蔚蓝档案主题网页

个人网页作业，共 5 个页面，使用 HTML + CSS 内联样式实现，无外部依赖。

## 页面

| 文件 | 内容 |
|---|---|
| `index.html` | 首页（全屏背景视频 + 入场按钮） |
| `characters.html` | 角色介绍 |
| `story.html` | 剧情背景 |
| `art.html` | 画工美术 |
| `music.html` | 音乐欣赏 |

## 目录结构

```
.
├── index.html
├── characters.html
├── story.html
├── art.html
├── music.html
└── images/            # 图片、背景视频、背景音乐
```

## 说明

- 页面间链接、图片、音视频全部使用**相对路径**，可直接部署到 GitHub Pages。
- 图片已压缩至 1920px 以内，兼顾清晰度与加载速度。
